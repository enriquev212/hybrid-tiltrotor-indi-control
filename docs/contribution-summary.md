# Contribution Summary

This document summarizes the public contribution scope for the INDI Research Project on hybrid tilt-rotor UAVs.

## Contribution Area

The work presented here is at system and control-architecture level:

- study of cascaded INDI control for hybrid tilt-rotor UAV trajectory tracking;
- connection between position/velocity tracking errors and virtual acceleration commands;
- analysis of local control-effectiveness modelling for the outer-loop controller;
- documentation of weighted least-squares allocation under actuator limits and preferences;
- interpretation of tracking, control-effort, and stability results;
- preparation of selected diagrams and figures from the Research Project material.

## Public Scope

This repository contains a public overview of the work, together with the complete RP report and final defense deck. It does not contain the complete simulator, detailed controller implementation, tuning files, or raw simulation logs.

## Collaboration Context

The Research Project was completed in an academic collaboration context. This public repository should be understood as a limited project overview, not as a full release of all project material.
