# Contribution Summary

This repository presents a collaborative academic Research Project. The report and defense deck list the project authors and supervisors; this public branch is organized to show the technical contribution areas represented in those deliverables.

## Contribution Areas Represented Here

- Nonlinear modelling of a hybrid fixed-wing quad-tiltrotor UAV.
- Ground-anchored segmented tether modelling with slack/taut behaviour.
- Cascaded INDI controller structure for guidance and stabilization.
- WLS control allocation across rotor thrusts and tilt-angle commands.
- Simulation campaign design: free-flight envelope, nominal tethered orbit, cable sensitivity and control effort.
- Interpretation of tracking, cable-tension, actuator-demand and stability results.
- Preparation of the final report, defense deck and explanatory figures included in this public branch.

## Public Scope

The repository includes the complete report and final presentation because they are the intended academic deliverables. It does not include the simulator source, controller implementation files, tuning/configuration files or raw logs.

This keeps the repository useful for external technical review without publishing implementation material from the broader collaboration.
