# Documentation

Public documentation for the INDI Research Project overview.

## Contents

- `contribution-summary.md`: contribution scope.
- `technical-summary.md`: architecture-level technical explanation.
- `assets/`: small curated set of representative figures and GIFs.
- `report/`: note on the omitted full report.
- `slides/`: note on the omitted full defense deck.

Full source code, complete report files, full slide decks, third-party papers, raw logs, and tuning files are intentionally excluded.
