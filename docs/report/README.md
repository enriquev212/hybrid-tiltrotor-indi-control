## Report Title

Incremental Nonlinear Dynamic Inversion (INDI) Control for Hybrid UAVs

## Authors

Enrique Valverde Sacristán and José Ricardo Furiati Aguilar

## Chapter Map

| Chapter | Focus |
|---|---|
| 1. Introduction | Motivation, hybrid UAV context, cooperative payload transport objective |
| 2. System Modelling | Tilt-rotor vehicle, frames, rigid-body dynamics, aerodynamics, actuator dynamics and tether model |
| 3. Incremental Nonlinear Dynamic Inversion | INDI principle, acceleration feedback, control effectiveness and allocation background |
| 4. INDI Controller Implementation | Cascaded outer/inner controller and WLS allocation structure |
| 5. Simulation Setup | Reference trajectories, nominal tethered case, sensitivity methodology and metrics |
| 6. Results and Discussion | Free-flight envelope, nominal tethered orbit, cable sensitivity, control effort and limitations |
| 7. Conclusion and Future Work | Summary, robustness interpretation and next steps toward cooperative transport |
| Appendix B | PID-vs-INDI quadrotor benchmark and real-flight comparison |

The root README and `docs/results-summary.md` provide a shorter path through the report for quick external review.
